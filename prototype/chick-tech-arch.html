The client sends a free-text founder brief. The API gateway routes it to the Orchestrator, which fans out to Fastino (intake structuring) and Cala (community + market data), merges results, scores them, and streams the ranked outreach kit back to the client. All state is persisted in the database for the refinement loop.

Security & Environment

All API keys stored as environment variables — never committed. Keys needed at runtime:

FASTINO_API_KEY · CALA_API_KEY · DATABASE_URL · JWT_SECRET · GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET

HTTPS enforced in production. CORS locked to known frontend origin. Input validated with Zod at every endpoint boundary. Rate-limiting on intake and discovery routes (10 req / min per user).
