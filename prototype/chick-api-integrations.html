Fastino — Intake Structuring

⚡
Fastino text-to-JSON
Step 1 — converts raw founder brief into structured ICP hypothesis
The founder types their idea in plain language. Fastino extracts structured fields: audience hypothesis, product category, stage, and tone signal. The output is treated as a hypothesis — Chick challenges and refines it, never accepts it as fact.

Request

POST https://api.fastino.ai/v1/extract
Authorization: Bearer {FASTINO_API_KEY}
Content-Type: application/json

{
  "input": "I'm building a tool for solo founders...",
  "schema": {
    "audience_hypothesis": "string",
    "product_category": "string",
    "stage": "idea|pre-launch|launched",
    "tone_signal": "casual|professional|technical",
    "pain_points": ["string"]
  }
}

Response fields

FieldTypeNotes
audience_hypothesisstringBest-guess ICP from the brief
product_categorystringe.g. "B2B SaaS", "Consumer app"
stageenumidea · pre-launch · launched
tone_signalenumDrives outreach copy tone
pain_pointsstring[]Extracted problems the product solves
confidence0–1 floatFastino's extraction confidence — flag if <0.6
Fallback: If confidence < 0.6, surface a clarifying question to the founder before proceeding to discovery. Never pass a low-confidence brief to Cala.

Cala — Community & Market Data

🔍
Cala Knowledge Search
Step 2 — verified community and company data across verticals
Cala supplies verified, sourced company and community data across Agro, Finance, HR, and other verticals. No hallucinated names, no stale lists. Real communities with real member counts and activity signals.

Request — Community Search

POST https://api.cala.ai/v1/search
Authorization: Bearer {CALA_API_KEY}

{
  "query": "solo founders productivity tools",
  "sources": ["reddit", "discord", "facebook"],
  "verified_only": true,
  "min_members": 500,
  "limit": 30
}

Response fields (per community)

FieldTypeNotes
idstringStable Cala community ID
namestringCommunity display name
platformenumreddit · discord · facebook · linkedin
member_countintegerVerified at last crawl
activity_score0–100Posts/week normalised score
promo_rulesstringExtracted mod rules re: self-promo
verified_atISO dateWhen Cala last confirmed this community exists
urlstringDirect link to community

Chick Internal API

Base URL: https://api.chick.app/v1

Method + PathNameDescription
POST /briefsCreate BriefAccepts raw text, triggers Fastino structuring, returns brief_id
GET /briefs/:idGet BriefReturns structured brief + structured_json
POST /briefs/:id/discoverRun DiscoveryCalls Cala, scores results, returns ranked communities
GET /communities/:id/kitGet KitReturns 7-day plan + copy for one community
POST /trackLog EventRecords attempt outcome (yes/no/silence/interested)
POST /briefs/:id/refineRefine LoopRe-runs scoring with tracking data, returns updated rankings
